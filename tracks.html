TRACK_A · 游戏策划（含技术策划 TP） DESIGN / TP
策划的最小可行路线
  • 读书打底：《游戏设计艺术》《体验引擎》两本足够入门，读的时候对着自己玩过的游戏做验证。
  • 拆解报告：每周拆一个系统或关卡（战斗节奏 / 抽卡数值 / 新手引导），写 2000 字以上——这就是策划的核心作品集。
  • 动手能力：Unity 里能摆关卡、写简单脚本；Excel 数值表必须熟练（VLOOKUP、模拟器）。
  • TP 加分项：Unity C# 或 UE 蓝图能跑通，就能做技术策划，缺口比纯案头大。
indienova 独立游戏社区 机核 GCORES 作品 = 拆解报告 + 可玩原型 + 数值表
TRACK_B · 引擎 / 工具开发 ENGINE / TOOL
引擎工具的最小可行路线
  • 前提：先走客户端 1~2 年的逻辑仍然成立——工具岗要理解使用者的痛点，应届直招极少。
  • C++ 硬功夫：内存模型、智能指针、多线程；图形学 GAMES 101/202 是必修不是选修。
  • 练手项目：给自己的 Unity 项目写编辑器扩展（批量资源处理 / 数据表格导入工具），这就是最好的作品。
编辑器扩展 = 入门作品 建议客户端转岗进入
TRACK_C · 美术（原画/3D/动作/特效） ART / VFX
美术的最小可行路线
  • 先选细分再投入：原画拼造型与设计；3D 场景/角色拼软件链（Blender/Maya → Substance → 引擎）；动作拼动态审美；特效拼"技术+审美"复合——对数媒技最友好的是特效 VFX。
  • 基本功不能省：速写、结构、色彩，每周固定练习量，课内强度不够就自己补。
  • 作品集：ArtStation / 米画师，宁缺毋滥，10 张精品 > 50 张练习。
  • 特效岗：Unity 粒子系统 / UE Niagara + Houdini 入门，作品直接在引擎里录屏。
ArtStation VFX 与 TA 路线互通
TRACK_D · 服务端 / QA / 发行 SERVER / QA / PUB
其他出口的最小可行路线
  • 服务端：Go 或 Java 或 C++ 选一门 → 网络（TCP/HTTP）→ 数据库（MySQL/Redis）→ 写一个多人 Demo（帧同步或状态同步）。和数媒技课程重合度低，适合纯技术流。
  • QA 测试：入门靠细心与用例思维，天花板靠自动化（Python + 引擎测试框架），能写自动化脚本的测试很值钱。
  • 发行运营：偏数据与商务，技术背景在"懂游戏能和研发对话"上是优势，但不算研发岗，慎重选择。
服务端作品 = 联机 Demo QA 别只会点点点
