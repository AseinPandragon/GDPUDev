■ 大学四年怎么走
4-YEAR PLAN
按 2024 级培养方案的课程节奏编排 · 以教务最新通知为准
1
大一 · C 语言（指针不过关不算过关）
C 语言指针、内存布局玩到能给别人讲明白
做什么：C 语言课的目标不是 90 分，是指针和内存模型彻底想通：写一个不依赖库函数的字符串库（strlen/strcpy/strcmp 自己实现）、一个简单的动态数组——报错全自己调。
验收标准：能画出一维指针、二维指针、数组与指针在内存里的真实布局图，并解释段错误是怎么发生的。
避坑：C 是这门方向唯一的"必修语言"——C 没过关，后面 C++ 的每一页都在还债。
2
大二 · 现代 C++（11/17 特性落地）
用现代 C++ 写一个 1000 行级的无 GUI 小系统 + 手撕数据结构
做什么：学 C++ 官方文档（Microsoft C++ 参考）的现代特性（智能指针、移动语义、RAII），做一个 1000 行级小系统（如日志库：分级写入、异步落盘、轮转），同步手撕常用数据结构（vector/map 的简化版）。
验收标准：日志库被你的其他练习项目真实引用；手撕结构能讲清每种操作的复杂度取舍。
避坑：只会背"智能指针防泄漏"，说不出"什么时候 shared_ptr 反而有害"——现代 C++ 的面试就是这么问的。
3
大三 · 读源码（挑一个模块读透）
读一个开源引擎/框架的完整模块并写系列笔记，宁深勿广
做什么：选一个够得着的开源项目深入：C++ 方向读 O3DE（docs.o3de.org）或 UE 某模块（UE 官方文档）；Rust 方向读 Bevy（官方 Learn） 的 ECS 实现——目标是一个模块（如日志、序列化、调度），从入口到每条分支全部读懂，写 5~8 篇系列笔记。
验收标准：系列笔记发到知乎/CSDN，收到至少一条有质量的讨论或指正。
避坑：从主函数开始通读是读源码最差的方式——从一个你好奇的行为（"这行日志是谁打的"）倒着追进去。
4
大四 · 专项面试（与后端同卷，题库通用）
C++ 面试专项：虚函数表、移动语义、内存对齐、多线程，全部落到白板
做什么：分块刷题——语言（虚函数机制、移动语义、智能指针实现）、系统（进程线程协程、内存管理）、手写（智能指针简化版、线程安全队列）；每块整理自己的答案文档，源码笔记作为"实战证据"附在简历后。
验收标准：模拟面试三轮，追问三层不倒。
避坑：八股 + 源码笔记要配套——只背八股的，一句"你读过哪个项目的这块代码"就破防。
■ 作品集长什么样 · 常见误区
PORTFOLIO & TRAPS
作品集定生死 · 别在错误方向上努力
  • 标配：源码阅读笔记 + 一个小型引擎模块实现（内存池/序列化/任务系统）；
  • 误区：没读过源码只背八股——追问一句就露馅；
  • 加分：给开源引擎提过 PR 或 issue，哪怕是小的。
