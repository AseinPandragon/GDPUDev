■ 这个细分到底在拼什么
WHAT IT TAKES
先看清门槛 · 再决定要不要投入
  • 图形 API：Vulkan / Metal / D3D12 至少理解一个抽象层（OpenGL 入门起步）；
  • GPU 硬件模型：渲染管线阶段、显存与带宽为什么是移动端瓶颈；
  • Shader 编译与变体：变体爆炸、编译缓存这些工程问题；
  • 渲染特性实现：从原理到跨设备兼容。

■ 这个岗位的一天 · 实际工作内容
A DAY IN LIFE
入职前先知道每天到底在干什么
  • 上午：看渲染 crash——驱动差异是噩梦来源，同一 Shader 不同设备表现不同；
  • 主力时间：实现渲染特性——新特性、兼容性修复；
  • 抓帧分析——GPU 耗时逐 pass 分析；
  • 产出物：渲染模块代码 + 各平台验证报告。

■ 大学四年怎么走
4-YEAR PLAN
按 2024 级培养方案的课程节奏编排 · 以教务最新通知为准
1
大一 · 双底子（数学 × C）
线性代数几何直觉 + C 语言指针，两个地基同时打
做什么：①线代用 3Blue1Brown《线性代数的本质》 建立几何直觉，再回课本刷题；②C 语言指针与内存模型玩透（同 runtime 页的大一标准：手写字符串库、画内存布局图）。
验收标准：能解释"投影矩阵为什么把 z 值变成非线性"，能画指针数组内存图。
避坑：图形底层的每一页教材都在用线代——这门课欠的债，后面逐页偿还还带利息。
2
大二 · OpenGL 起步（从黑屏到三角形）
跟 LearnOpenGL 做完基础篇：窗口、三角形、纹理、变换、光照
做什么：跟 LearnOpenGL（有中文翻译）做完入门与光照章节——每章代码手打不复制，重点理解"初始化上下文→顶点数据→着色器→绘制调用"每个环节为什么存在；理论同步刷 GAMES101（B站）。
验收标准：不对照教程，能从空项目写出一个带纹理和 Blinn-Phong 光照的旋转立方体。
避坑：OpenGL 报错经常一片黑屏无提示——学会用 glGetError 和调试输出，排查能力从这里开始练。
3
大三 · 迷你渲染器（图形底层的硬通货）
写一个 CPU 软件光栅器（推荐）或 Vulkan 小渲染器，全程自己实现
做什么：二选一——①软件光栅器（更推荐）：纯 CPU 实现 MVP 变换、三角形光栅化、深度缓冲、纹理采样，参考 Scratchapixel（免费图形学教程）；②Vulkan 路线：跟 vkguide.dev 做一个最小渲染器。
验收标准：软件光栅器能加载一个 obj 模型并正确渲染带纹理旋转动画；每一行都能解释用途。
避坑：这是图形底层方向最有说服力的作品——但只有全程自己写（不抄模板）才有效，面试官会让你现场改一行看结果。
4
大四 · 专项面试（API + 硬件 + 实现三层）
图形底层面试专项：同步原语、GPU 硬件模型、手写渲染管线口述
做什么：分三层准备——API（Vulkan 的 synchronization、validation layer 报错怎么读）、硬件（为什么带宽是移动端瓶颈、TBDR 架构常识）、实现（口述手写渲染管线全步骤，对应你的光栅器）。作品集收口：光栅器传 GitHub + 每阶段 README。
验收标准：模拟面试：让你现场给自己的光栅器加一个特性，你能说出改哪里。
避坑：这个方向面试必问你的渲染器细节——不是自己写的部分千万别放。
■ 作品集长什么样 · 常见误区
PORTFOLIO & TRAPS
作品集定生死 · 别在错误方向上努力
  • 标配：软件光栅器或迷你渲染器——图形底层方向的硬通货；

  • 误区：只会引擎里拖材质没碰过图形 API，那不是图形底层。
