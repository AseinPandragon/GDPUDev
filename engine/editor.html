■ 这个细分到底在拼什么
WHAT IT TAKES
先看清门槛 · 再决定要不要投入
  • 引擎扩展 API：Unity Editor Scripting / UE Editor Utility 的系统能力；
  • 工具 UI 开发：IMGUI、UI Toolkit 或 Slate，给同事做"能用的"界面；
  • 序列化与数据：自定义数据怎么存、怎么防呆；
  • 工作流思维：用户是同事，工具好不好用有真实反馈。

■ 这个岗位的一天 · 实际工作内容
A DAY IN LIFE
入职前先知道每天到底在干什么
  • 上午：收组内需求——关卡策划抱怨批量摆放太累，这就是需求来源；
  • 主力时间：写编辑器扩展——从脚本到带界面的工具；
  • 发布与迭代——内部版本收反馈，工具是养出来的不是一次写完的；
  • 产出物：编辑器工具 + 使用文档。

INTERVIEW MAP

手写题做一个自定义 Inspector 或 EditorWindow，现场演示思路；
设计题给关卡策划设计一个批量摆放工具——考需求抽象；

UX 题工具没人用怎么办——考迭代意识而不是甩锅用户。
