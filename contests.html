CONTEST_01 · 教育部 A 类学科竞赛 4C · 数媒游戏与交互设计
中国大学生计算机设计大赛（4C）
  • 是什么：教育部《全国普通高校大学生竞赛分析报告》竞赛目录内赛事，我国最早面向本科生的大赛之一，2008 年首届，现每年一届。
  • 对口赛项：11 个大类里有「数媒游戏与交互设计」——就是给数媒技准备的赛道，游戏 Demo 直接能报。
  • 流程与时间：校赛 → 省赛 → 国赛三级。每年上半年省赛（约 3~5 月提交），暑假国赛决赛。关注官网通知 + 本校教务处/学院的校赛通知。
  • 为什么打：保研加分、综测、评奖评优都认的"硬奖"，这是 Game Jam 和企业赛给不了的。
  • 怎么打：组队 1~3 人，按岗位分工（程序 + 美术 + 策划）；作品要完整可玩 + 文档规范，评审很看重选题立意与完成度。
4C 官网 保研 / 综测可用 数媒技直接对口赛项 先过校赛再谈国赛

CONTEST_02 · 网易 NETEASE ACADEMY
网易 · 聚光灯高校游戏开发者大赛（及 MINI-GAME 等系列）
  • 是什么：网易游戏学堂面向高校的开发者赛事体系，含聚光灯高校游戏开发者大赛、MINI-GAME 大赛（曾联合《蛋仔派对》开设双赛道）、高校原画设计大赛等。
  • 为什么打：名次靠前有机会拿面试直通卡 / 实习 offer，网易的校招暑期实习转化率高，是进大厂最短的路径之一。
  • 时间线：各赛事报名期多在年初~年中，每年赛道和档期会变，盯紧游戏学堂的活动页。
  • 怎么打：企业赛看重"玩法创意 + 完成度"，评委是网易在岗制作人；比起堆美术量，一个机制立得住的可玩原型更有竞争力。
网易游戏学堂 · 活动页（历年赛事入口） 面试直通 / 实习转化 关注当届赛道与档期
CONTEST_03 · 腾讯 TENCENT GAME INSTITUTE
腾讯 · 高校游戏创意制作大赛（已升级：腾讯游戏创作大赛）
  • 是什么：腾讯游戏学堂主办的高校游戏赛事，早年的高校创意制作大赛现已升级为面向更广泛开发者的"腾讯游戏创作大赛"（2026 届赛期约 4 月~11 月，线上）。
  • 为什么打：获奖作品团队有机会进入腾讯面试绿色通道 / 青训计划，评委来自天美、光子等工作室群。
  • 时间线：全年长周期赛事（报名→初赛→决赛横跨大半年），适合拿一个打磨过的完整项目去打，别拿 48 小时 Jam 作品硬冲。
  • 怎么打：官网历年获奖作品都公开，先拆解近三年的获奖名单和作品视频，看清腾讯评委的口味再立项。
腾讯游戏学堂 · 官网 高校大赛作品合集 面试绿色通道 长周期 · 适合完整项目

CONTEST_04 · 48H 极限开发 GAME JAM
CiGA Game Jam / Global Game Jam 中国区
  • 是什么：48 小时内按主题现场做出一款完整游戏。华语圈最大的是 CiGA（中国独立游戏联盟）主办的线下 Game Jam，每年暑期在十几个城市同时开场；Global Game Jam 中国区每年 1 月末开赛。
  • 为什么打：最快暴露"你以为会、其实不会"；顺便认识能长期组队的伙伴——很多后来的参赛队/项目组就是 Jam 现场凑出来的。
  • 怎么打：别贪大，主题出来后 1 小时内定核心玩法，剩余时间全花在"把它做完"上；美术不够就用免费素材，评审看的是完成度和主题契合。
CiGA Game Jam 报名页 大一就能打 队友储备库
CONTEST_05 · 线上常驻 ALWAYS ON
Booom / indienova 等线上创作活动
  • 是什么：indienova 等独立游戏社区常年举办线上主题创作活动（如 Booom 接力），线上参与、无地域门槛，学期内也能打。
  • 为什么打：线下 Jam 一年只有几场，线上活动可以当"月度练手"；作品发布在社区还能直接收到玩家反馈。
indienova 社区 学期内练手用
⚠️ 三个提醒 ① 各赛事每年赛道、时间、政策都会变，报名前一律以官网当届通知为准，本页只负责帮你建立全景。② 保研/综测加分以本校教务文件认定的竞赛目录为准，打之前先确认 4C 在你们学校认不认。③ 企业赛的报名入口每年换页面，认准官方域名（163.com / qq.com），别在第三方代报名网站上浪费时间。
