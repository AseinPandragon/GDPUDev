STEP_01 · 思维打底（随时可开始） READ + THINK
两本书 + 带着"框架"玩游戏
《游戏设计艺术》（The Art of Game Design）和《体验引擎》（Designing Games）两本足够入门，前者给你设计词汇和视角，后者讲透机制与情绪的关系。读的时候对着自己玩得最深的一款游戏做验证：它的核心循环是什么？新手引导在哪一步把你留下/劝退？从"玩过"到"能说清为什么好玩"，就是策划的第一道分水岭。
《游戏设计艺术》 《体验引擎》 核心循环 / 心流 / 钩子
STEP_02 · 拆解输出（核心作业，每周一篇） DECONSTRUCTION REPORT
拆解报告是策划的"代码"——它就是你的作品集主体
每周拆一个系统或关卡（战斗节奏 / 抽卡数值 / 新手引导 / 关卡曲线），每篇 2000 字以上，固定三段式：
  • 画出来：把系统画成流程图 / 状态机，画不出来说明没拆懂；
  • 反推数值：从结果反推公式和参数区间（掉率、成长曲线、经济产出）；
  • 给出改法："如果是我来做"——这段最见功力，也是面试官最想看的。
发到知乎 / indienova 攒反馈，面策划岗时直接甩链接。

STEP_03 · 动手实现（大二下~大三） BUILD IT IN-ENGINE
策划也要会"造"：关卡原型 + 数值表 + TP 技能
  • 关卡原型：Unity 里用基础几何体摆可玩关卡（不用美术资源），验证节奏与引导——会摆关卡的策划在面试里是降维打击。
  • Excel 数值表：VLOOKUP、条件格式、蒙特卡洛模拟要熟练；交一份"抽卡概率模拟器"或"经济系统演算表"级别的作业。
  • TP（技术策划）加分项：Unity C# 能写简单玩法脚本，或 UE 蓝图能跑通逻辑——技术策划岗位缺口比纯案头大，数媒技背景天然对口。
Unity Learn 官方教程 Unity 官方文档 会摆关卡 + 会写脚本 = TP 门槛
STEP_04 · 作品集与投递（大三上启动） PORTFOLIO + INTERVIEW
策划的作品集长什么样，面试考什么
  • 标配三件套：3~5 篇拆解报告（在线可读）+ 1 个可玩关卡原型 + 1 份数值演算表。
  • 面试必考题："拆一款你玩得最深的游戏"——答案就是你 STEP_02 攒的报告，现场讲比背模板强一百倍。
  • 投递顺序建议：技术策划 / 关卡策划优先（对口），系统策划次之；文案策划竞争极卷——除非文字功底恰好是你的强项，否则谨慎选择。
报告可在线访问 > PDF 附件 知乎专栏 = 策划的 GitHub
💡 一句话总结策划方向 策划 = 思维框架（两本书）× 持续拆解输出（每周报告）× 引擎动手（原型 + 数值 + 脚本）。纯案头卷文笔，技术策划缺人——数媒技请优先打 TP 和关卡实现。

■ 亲历口述区 · 策划篇
WAITING
教程里不会写 · 只有真做过才碰得到的部分
学长说 · 酥小白OvO 2026-09-24
"做游戏尤其是做游戏策划，对于小白永远都是：热爱玩游戏、多玩游戏"
这句话是整个策划方向的地基，值得单独写进路线里。"热爱"决定你能不能熬过前两年的枯燥（拆解和数值表一点也不浪漫）；"多玩"决定你的弹药库——策划面试里聊得最深的那个游戏，一定是你玩得最久的那个。但注意"多玩"不等于"泛玩"：同一款游戏玩到能拆出核心循环、数值节奏和留存钩子，比走马观花玩一百款更有用。玩，然后按本页 STEP_02 的方法拆——这就是小白最短的路。
热爱玩游戏 多玩游戏 多玩 ≠ 泛玩 · 玩透一款再谈拆
学长说 · 凝星眸 2026-09-24
"多积累，不止游戏"
这是上一条的续集，也是很多新人想反了的地方：策划的输入源越杂越好。不同媒介练的是不同的"肌肉"——摄影练构图与视觉表达（关卡引导、场景氛围直接受益）；短视频练节奏（前 3 秒留人的功夫和手游前三分钟留人是一回事）；小说练叙事结构与代入感（任务文案、世界观拆解的底子）。玩得杂 + 看得杂，素材库决定你以后输出的上限。做拆解报告没题目写的时候，就从这些地方找：一部好电影的三幕结构、一条爆款短视频的信息密度，都是可拆的对象。
摄影 → 视觉表达 短视频 → 节奏 小说 → 叙事结构 输入的广度决定输出的上限
