SEC.01

岗位全景图：数媒技在游戏行业能去哪

数媒技的特点是"软硬都沾一点"，这决定了某些岗位对我们特别友好

技术美术 TA

数媒技最对口 ⭐

美术和程序之间的翻译官：写 Shader、搭渲染管线、做美术工具、优化性能。既要懂一点代码，又要有审美和美术常识——恰好是数媒技的课程结构。人才缺口长期存在，竞争比纯程序岗小。

缺口大渲染 / 管线 / 工具 / 绑定 四大细分⬇ 本文深挖

客户端程序（Unity / UE）

数媒技主流出路

用 C#（Unity）或 C++（UE）写玩法逻辑、UI、战斗系统。数媒技走这条线的人最多，门槛是"能独立做出一个完整能玩的游戏"，而不是"会用引擎拖 UI"。

岗位多、竞争也多C# / C++光会拖组件不够

引擎 / 工具开发

进阶方向

给项目组造轮子：编辑器扩展、资源管线、性能工具，甚至引擎底层。通常从客户端程序转过去，C++ 功底和图形学要求更高，应届直接进的少。

C++ 深水区应届直招少

游戏策划（系统/关卡/数值/文案）

技术背景加分

设计玩法、关卡、数值和剧情。数媒技的技术背景在"技术策划 TP"和关卡实现方向是明显加分项——能自己用引擎摆关卡、写简单脚本的策划非常吃香。纯案头策划则更卷文笔和思维。

技术策划缺口作品=拆解报告+关卡原型

美术（原画/3D/动作/特效）

看个人天赋投入

2D 原画、3D 建模、绑定动画、特效。纯美术岗拼的是作品集里画/模型的硬实力，数媒技的美术课强度通常不够，需要额外大量练习。特效（VFX Artist）介于美术和技术之间，是美术岗里对程序友好的一支。

作品集定生死课内训练强度不够

服务端程序 / 音频 / QA / 发行运营

其他出口

服务端偏后端开发（Go/Java/C++），和数媒技课程重合度低但可转；音频岗国内坑位很少；QA 测试入门容易但天花板靠自动化测试技能；发行运营偏商务和数据，不算研发岗。都可以作为备选了解。

备选了解即可
SEC.02

深挖方向 01：技术美术 TA

学习路线按"先打地基、再进引擎、边做项目边补"组织，顺序比速度重要
STEP 01 · 地基（大二前打完最划算）

图形学入门：GAMES 101 → 202 → 104

这是国内图形学入门公认的起点，B站就能看，不用管它是哪年录的——图形学基础的衰减期比框架长得多。

  • GAMES 101 现代计算机图形学入门：变换、光栅化、着色、光线追踪。作业认真写，光看不行。它决定你能不能看懂 Shader 背后的数学。
  • GAMES 202 高质量实时渲染：阴影、全局光、实时降噪——直接对应游戏渲染岗的日常话题。
  • GAMES 104 现代游戏引擎：建立"引擎全局观"，知道一个引擎由哪些系统拼起来。作业可以量力而行，但一定要看完，它会改变你看 Unity/UE 的方式。

配套工具书：《Real-Time Rendering》别当教材通读，当字典查——做项目碰到 "这个效果原理是什么" 再回去翻对应章节，吸收效率高得多。

STEP 02 · 引擎双线（与 STEP 01 并行）

Unity 里动手写，UE 里开眼界拆

两条线不是二选一，是分工不同：

  • Unity 线（动手）：ShaderLab / HLSL 从最简单的 Unlit 开始写起，逐个实现卡通着色、描边、溶解、billboard、屏幕后处理。每个效果录一段视频存进作品集文件夹。
  • UE 线（拆解）：去看官方工程示例（如 Lyra、City Sample），拆解官方插件——重点不是学 UE API，而是看"一个工业级项目怎么组织材质库、后处理栈、资产管线"。见过好结构，才知道自己写的有多野。

图文资讯和深度分析主要靠 知乎：搜 TA / 渲染相关专栏，遇到讲透一个效果的的文章就收藏归档，建自己的知识库。

STEP 03 · 跟人学（穿插全程）

关注这些 UP 主 / 作者：kerry、月神、三彩

自学最容易死在"不知道自己不知道什么"上。跟着活跃的 TA 向作者走，他们的更新内容就是行业里当下在关心的问题，比自己闷头翻教程高效。遇到系列教程就跟着把 Demo 做一遍，光收藏不算学。

B站：kerry月神三彩知乎 + B站双平台跟更

STEP 04 · 作品集（大三上必须启动）

TA 的作品集长什么样

  • 3~5 个有讲解的渲染效果 Demo：每个附"效果视频 + 实现思路 + 对比截图（开启/关闭）"，最好附 GitHub 仓库。
  • 1 个工具型作品：编辑器扩展或美术提效小工具，展示你不只会写特效。
  • 1 个"进过真机"的项目：哪怕是小项目，只要在真机上跑过、优化过，含金量就超过十个只在编辑器里好看的 Demo。
亲历

我们真踩过的坑（为什么"课本外"的东西更重要）

WAR STORY // 渲染排序

UI 弹窗怎么调 Layer 都不生效？因为 URP 里 Layer 根本不管排序

技能弹窗死活显示不出来/层级错误，查了半天 Layer 剔除——真相是：URP 的 Overlay 相机栈里，Layer 只管相机剔除，实际显示顺序由相机列表顺序和 Sorting Layer 决定。最后靠把弹窗挂到最上层 Canvas + 指定 Sorting Layer 才解决。GAMES 101 教你渲染原理，但这种"引擎具体怎么排"的知识，只能靠在项目里被坑一次。

WAR STORY // 深度与遮挡

世界空间图标被场景模型"吃"掉一半：ZTest 的教训

给技能做箭头指示图标，按物体包围盒定位后仍然被挡——精灵枢轴和半深度都没算进去。世界空间 UI/图标必须在锚点定位之外额外考虑与相机的深度关系（沿相机方向再推一段），否则 ZTest 会替你做"正确的"遮挡，挡掉你想显示的东西。

WAR STORY // 资源与打包

编辑器里好好的，真机上材质全变粉色（或直接报空）

运行时用 Shader.Find 动态建材质，编辑器一切正常，真机上直接 ArgumentNullException 中断加载——因为没被资源引用的 shader 打包时会被裁剪，真机上 Find 返回 null。正确做法是多候选查找 + 内置材质兜底 + 全失败就跳过赋值。这就是"打包管线"知识：不进项目你永远碰不到。

WAR STORY // 粒子特效

循环特效越叠越亮：burst 粒子的 duration 陷阱

把循环特效 main.loop 打开后，画面上的粒子一轮比一轮多——原因是 ParticleSystem 的 duration 没有覆盖到最长粒子寿命，burst 每个周期都在叠。调 VFX 不是拖拖参数，每一条曲线和时长都要能解释。

【待补充 · 学长亲历口述区】　你自己的入坑契机、第一次写出能看的 Shader 是什么时候、被哪门课劝退/点醒——这些只有你能写。说一段，我们就填进来。
💡 给 TA 方向的一句话总结：TA = 图形学底子（101/202/104 + Real-Time Rendering）× 引擎实操（Unity 写 + UE 拆）× 项目毒打（真机、管线、性能）。三个因子缺一个，面试时都会露馅。
SEC.03

不分方向都成立的几条

这些是行业共识里最经得起时间的部分

作品集 > 绩点（但别挂科）

游戏公司校招看的是"你做过什么"：能跑的 Demo、Play 商店/EXE 直接双击的成品、GitHub 仓库。绩点保底不挂科即可，时间要大量投给项目。

参加 Game Jam，越早越好

48 小时内做一款完整游戏，是最快暴露"你以为会、其实不会"的方法。LiGameJam / CiGA 等活动线上线下都有，大一暑假就可以开始参加。

做完整的项目，别囤半成品

十个 30% 完成度的项目不如一个 100% 的。完整意味着：能安装、有音效、有结算、能重开。我们做完整项目时学到的东西（打包、热更、真机适配）没有一样出现在教程里。

英语不是加分项，是基础设施

官方文档、引擎 release note、图形学论文、报错搜索——一手信息全是英文。靠翻译软件可以活，但速度差一截，日积月累就是差距。

把 AI 当杠杆，别当拐杖

AI 能帮你解释报错、生成模板、查 API 用法，效率翻倍；但基础概念跳过 AI 直接要答案，你就失去了建立自己理解的机会。判断标准：让 AI 写的东西，你能逐行给别人讲明白吗？

实习时间线（现实版）

大二暑假前：作品集启动 + 第一个完整项目。大三上：秋招提前批开始投（别以为秋招是"秋天"，七月就开始了）。大三暑假：日常实习。等大四再准备就晚了，这条线每年都在提前。

SEC.04

就业现实检查

不贩卖焦虑，也不画饼
  • 行业有周期。招聘量随版号、市场波动明显，你入学时的行情和毕业时可能完全不同。所以选方向优先选"底层能力可迁移"的（图形学、C++、工程能力），而不是押注某个风口引擎。
  • 大厂 / 中小厂 / 外包体验完全不同。大厂分工细、螺丝钉但体系化；小厂什么都干、成长快但野蛮；外包是不少人的第一跳板，不丢人，但要清楚它是一跳不是终点。
  • 薪资不写在指南里。网上流传的数字水分大且随年份剧烈变化，建议直接去面几轮、或找在职学长要当届 offer 实况，比任何攻略都准。
  • 数媒技不是"劣势专业"。游戏行业里技术+审美复合背景的人本来就该走复合岗位（TA、TP、特效），对口的赛道你不走，非要跟科班 CS 拼 pure 程序岗才是把自己放错位置。
