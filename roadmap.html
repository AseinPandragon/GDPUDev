POSITION_01 · 最对口 ⭐ FIT: ★★★★★
技术美术 TA

POSITION_04 · 技术背景加分 FIT: ★★★★
游戏策划（系统/关卡/数值/文案）
设计玩法、关卡、数值和剧情。数媒技的技术背景在"技术策划 TP"和关卡实现方向是明显加分项——能自己用引擎摆关卡、写简单脚本的策划非常吃香。纯案头策划则更卷文笔和思维。点下方展开细分方向。
策划不是一个岗位，是一组岗位的统称：共同点是"对游戏体验负责"，分歧点在于你负责体验的哪一层——规则（系统）、概率与曲线（数值）、空间与节奏（关卡）、还是故事（文案）。技术策划 TP 则是用引擎把设计落地的复合岗，是数媒技最顺的入口。校招通常不细分死，但作品集方向要和投的细分对上。
系统策划 拼逻辑拆解与规则设计，画流程图、写规则文档，门槛：逻辑拆解力 + Excel。 进入细分页 ➔ design/system 数值策划 战斗/成长/经济公式与曲线建模，最看数理，高数概率论学好就是底子。 进入细分页 ➔ design/numeric 关卡策划 在引擎里白盒摆关卡、控节奏曲线，数媒技的引擎课直接对口。 进入细分页 ➔ design/level 文案 / 叙事策划 世界观、剧情、任务文本，卷文笔与叙事结构，坑位相对少。 进入细分页 ➔ design/narrative 技术策划 TP ⭐ 数媒技优势位 用引擎 + 脚本把设计落地，程序×策划复合，缺口明显。作品集：拆解报告 + 关卡原型 + 能玩的 demo。 进入细分页 ➔ design/tech-design

POSITION_05 · 看天赋投入 FIT: ★★★
美术（原画/3D/动作/特效）
美术同样是"一组岗位"的统称。纯美术岗拼的是作品集里画/模型的硬实力，数媒技的美术课强度通常不够，需要额外大量练习。点下方展开细分方向。
游戏美术按"生产什么资产"分工：平面的交给原画/UI，立体的交给 3D 建模，让资产动起来的是动作绑定，让画面"炸"起来的是特效。共同门槛是作品集——细分之间的差距比"美术 vs 程序"的差距还大，选错细分再努力也难。特效 VFX 介于美术和技术之间，是美术岗里对数媒技最友好的一支。
2D 原画 / 插画（平面设计） 拼素描色彩基本功与风格，PS/Procreate，大一《造型基础》（素描课）就是起点。 进入细分页 ➔ art/illustration 3D 建模（角色/场景） Maya/Blender/ZBrush，次世代流程：高模→拓扑→烘焙→PBR 贴图。 进入细分页 ➔ art/modeling 动作 / 绑定 骨骼绑定、动画状态机、动作捕捉，课内《三维动画技术》对口。 进入细分页 ➔ art/animation 特效 VFX ⭐ 数媒技首选 Unity 粒子 / UE Niagara + 少量 Shader，美术岗里技术溢价最高、最缺人的一支。 进入细分页 ➔ art/vfx UI / 界面美术 界面、图标、HUD、动效，课内《游戏视觉设计》《构成设计》对口。 进入细分页 ➔ art/ui 往 TA 走 美术功底 + 程序能力交叉的顶点方向。 进入 TA 页 ➔ ta

■ SEC.02 · 不分方向都成立的几条
6 RULES
行业共识里最经得起时间的部分
RULE_01 PORTFOLIO FIRST
作品集 > 绩点（仅对就业路线成立）
这条只适用于毕业直接就业的路线：游戏公司校招看的是"你做过什么"——能跑的 Demo、双击就能玩的成品、GitHub 仓库，绩点保底不挂科即可。但如果你的路线是保研 / 考研 / 考公，权重完全反过来：
  • 保研：绩点和排名是硬门槛，缺一口都进不了名单，项目经历只是面试加分项——绩点优先，别被"作品集>绩点"带偏；
  • 考研：初试看统考成绩，绩点影响不大，但别挂科；复试时项目经历是实打实的加分项；
  • 考公/考编：绩点基本无关，毕业证和学位证到手就行。
先定路线，再决定时间往作品集还是绩点上砸——两头都要的人，建议按"绩点过保研线 + 作品集同步养"双线走。
RULE_02 GAME JAM ASAP
参加比赛，越早越好
48 小时 Game Jam 是最快暴露"你以为会、其实不会"的方法；教育部的 4C、网易腾讯的高校赛则能给你"硬奖"和企业面试通道。比赛全景与攻略已单独成页。
进入比赛大全页
RULE_03 FINISH THINGS
做完整的项目，别囤半成品
十个 30% 完成度的项目不如一个 100% 的。完整意味着：能安装、有音效、有结算、能重开。我们做完整项目时学到的东西（打包、热更、真机适配）没有一样出现在教程里。
RULE_04 ENGLISH = INFRA
英语不是加分项，是基础设施
官方文档、引擎 release note、图形学论文、报错搜索——一手信息全是英文。靠翻译软件可以活，但速度差一截，日积月累就是差距。
RULE_05 AI AS LEVER
把 AI 当杠杆，别当拐杖
AI 能帮你解释报错、生成模板、查 API 用法，效率翻倍；但基础概念跳过 AI 直接要答案，你就失去了建立自己理解的机会。判断标准：让 AI 写的东西，你能逐行给别人讲明白吗？
RULE_06 · 时间线 REAL TIMELINE
实习时间线（就业导向 · 现实版）
大二暑假前：作品集启动 + 第一个完整项目。大三上：秋招提前批开始投（别以为秋招是"秋天"，七月就开始了）。大三暑假：日常实习。等大四再准备就晚了，这条线每年都在提前。

这条是 RULE_01 的重要补充：上面"作品集 > 绩点"默认的是毕业直接就业的路线，但不是所有人都以"读完大学就工作"为导向——走保研、考研、考公的同学，绩点能高就尽量高。路线没想清楚之前，别急着把绩点当代价换项目时间；两条路都想要，就双线并行。

■ SEC.03 · 就业现实检查
NO SUGARCOATING
不贩卖焦虑 · 也不画饼
  • 行业有周期。招聘量随版号、市场波动明显，你入学时的行情和毕业时可能完全不同。所以选方向优先选"底层能力可迁移"的（图形学、C++、工程能力），而不是押注某个风口引擎。
  • 大厂 / 中小厂 / 外包体验完全不同。大厂分工细、螺丝钉但体系化；小厂什么都干、成长快但野蛮；外包是不少人的第一跳板，不丢人，但要清楚它是一跳不是终点。
  • 薪资不写在指南里。网上流传的数字水分大且随年份剧烈变化，建议直接去面几轮、或找在职学长要当届 offer 实况，比任何攻略都准。
  • 数媒技不是"劣势专业"。游戏行业里技术+审美复合背景是稀缺品，TA、TP、特效这些复合岗位对我们天然友好。但如果你就是喜欢写代码、想走纯程序岗，也完全可行——只是要自觉补齐 CS 基本功（数据结构、操作系统、网络），用项目和算法题证明自己。路没有对错，只有匹配不匹配。
