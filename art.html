STEP_01 · 选细分 + 基本功（大一开始） PICK ONE TRACK
四个细分，四种活法
  • 原画：拼造型与设计能力，内卷最重，画得不好就是不好；
  • 3D 建模（场景 / 角色）：拼软件链完整度与细节耐力；
  • 动作：拼动态审美与节奏感，懂引擎者优先；
  • 特效 VFX：拼"技术 + 审美"复合，对程序友好——数媒技首选。
无论哪个细分，基本功（速写、结构、色彩、镜头感）每周都要有固定练习量——课内强度不够就自己补，这笔账谁也替不了。
VFX 与 TA 路线互通 基本功每周固定量
STEP_02 · 软件链（跟着细分走） TOOL CHAIN
每个细分的标配工具链
  • 原画：Photoshop / Procreate（iPad 便携加分）；
  • 3D：Blender（免费，学起来零成本）→ Substance Painter（材质）→ ZBrush（高模雕刻，角色向）；
  • 动作：Maya（行业标准）+ 引擎内 Animation 视图；
  • 特效：Unity 粒子系统 → UE Niagara → Houdini（进阶必备，程序化思路）。
工具是手段不是目的，招聘看的是"用工具做出的东西"，不是"会多少软件"。
Blender 官网（免费开源） 3D：Blender → Substance → ZBrush 特效：Unity → Niagara → Houdini
STEP_03 · 引擎内落地（拉开差距的一步） IN-ENGINE DELIVERY
作品必须"进过引擎"才算数
游戏美术和插画 / 影视美术的分水岭就在这一步：资产要进引擎走完导入 → 材质 → 灯光 → 性能 → 录屏展示的完整流程。同一张原画，"PSD 里好看"和"引擎里好看"是两回事；同一个模型，五万面和五千面在手机上是两种命运。数媒技的程序基础在这一步全是优势——懂引擎的美术永远比纯美术稀缺。
Unity 官方文档 UE 官方文档 懂引擎的美术是稀缺品
STEP_04 · 作品集（宁缺毋滥） ARTSTATION FIRST
10 张精品 > 50 张练习
  • 平台：ArtStation 为主（国际通用），米画师 / 站酷为辅（国内接单）；
  • 3D 作品：必须附线框图 / 拓扑展示 + 引擎内渲染图，只放效果图会被当成"网上扒的"；
  • 特效作品：直接引擎录屏 + 节点图截图，讲清"这个打击感的节奏是怎么调的"；
  • 原画作品：放完整过程（草图 → 配色 → 细化），过程比结果更值钱。
ArtStation 宁缺毋滥 过程展示 > 只有成品
💡 一句话总结美术方向 美术 = 细分定位 × 基本功 × 引擎内落地。数媒技优先考虑特效 VFX（技术审美复合、和 TA 互通），纯原画赛道请先评估自己愿不愿意"课外练 3 倍"。

AIGC 已进工作流，但审美决定产出下限
  • 已在用：概念探索（MJ/SD）、AI 贴图与材质、动作 inbetweening 辅助——纯手搓概念图的岗位在缩减，会指挥 AI 的美术在升值；

  • 作品集提醒：慎放纯 AI 产出，评审最先问的就是"哪些是你画的"。
