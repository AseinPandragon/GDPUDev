■ 这个细分到底在拼什么
WHAT IT TAKES
先看清门槛 · 再决定要不要投入
  • 打击感：特效是为"手感"服务的，帧节奏、缩放曲线、屏幕震动比特效本身更核心；
  • 粒子与材质：粒子系统、序列帧、Shader 材质、顶点动画是四大件；
  • 性能意识：overdraw（透支填充率）是实时特效第一杀手，手机端尤其敏感；
  • 引擎原生：一切以引擎内实时表现为准，DCC 软件里好看不算数。

■ 大学四年怎么走
4-YEAR PLAN
按 2024 级培养方案的课程节奏编排 · 以教务最新通知为准
1
大二 · 引擎粒子入门 START
临摹 3 个经典特效
挑 3 个喜欢的游戏特效（刀光、命中、技能爆发各一），逐帧拆解后进 Unity 复刻——目标是"看起来像"：
  • 工具：Unity 粒子系统 + Shader Graph 入门，跟官方教程走完基础操作；
  • 方法：先逐帧拆目标效果（层数、贴图、节奏、颜色），列清单再动手，别凭感觉堆粒子；
  • 长线：开看 GAMES 101（B 站），不用急，它是你看懂 Shader 数学的地基；
  • 习惯：每个临摹作品录引擎内实机视频存档。
2
大二暑假 · 材质与图形学 GRAPHICS
Shader Graph 四件套 + 图形学起步
从"调粒子"升级到"写材质"，这是特效师和特效玩家的分界线：
  • Shader Graph：做出溶解、描边、流动、扭曲四个基础效果，理解每个节点背后的原理；
  • 工具：学会用 Frame Debugger / RenderDoc 查看一帧里粒子的开销——性能意识从现在建立；
  • 图形学：GAMES 101 继续推进，不用赶进度；
  • 输入：拆 5 个商业游戏的技能特效，记录它们的层结构和节奏设计。
3
大三 · 复刻 + 原创成套 RECREATE & CREATE
拆爆款 + 3~5 个完整效果进引擎
从临摹转向有自己判断的制作，每个效果都要能讲出设计思路：
  • 复刻：拆 3~5 个爆款游戏的技能特效并复刻进引擎（Unity、UE Niagara 各来几个）；
  • breakdown：每个效果配拆解图（粒子层级 / 贴图 / 曲线 / 打击节奏点）——拆解能力比效果本身更打动面试官；
  • 性能：overdraw 控制、LOD、合批——给至少一个效果做性能优化并记录前后对比数据；
  • 选修：三维特效、三维渲染技术、计算机图形学，课内能选的全选上。
4
大四 · Reel 成片 SHOWREEL
引擎实机 reel + 性能案例
特效师应聘的核心材料是一条引擎内实机录的 reel，外加一个性能优化案例：
  • Reel：45~60 秒，3~5 个效果，全部引擎内实机录制，配 breakdown 交替展示；
  • 性能案例：优化前后的 overdraw / 帧率对比数据——应届生最稀缺的加分项；
  • 面试高频题：打击感怎么调、粒子层数怎么规划、overdraw 是什么怎么压——都用作品回答；
  • 投递：VFX 岗缺口大、技术溢价高，见薪资招聘页。

■ 作品集长什么样 · 常见误区
PORTFOLIO & TRAPS
作品集定生死 · 别在错误方向上努力
  • 引擎内实机录屏：一切以引擎实时表现为准，DCC 软件渲染图不算数；
