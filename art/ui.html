💡 一句话定位 给游戏"做壳"的岗位：界面、图标、HUD、动效。本质是平面设计的游戏化——设计感是上限，切图规范与实现意识是下限，数媒技的构成设计课直接对口。
■ 这个细分到底在拼什么
WHAT IT TAKES
先看清门槛 · 再决定要不要投入
  • 信息层级：界面首先解决"玩家先看哪"，其次才是好看；
  • 图标语言统一：一套图标要有统一的形体语言、描边粗细、透视规则；
  • 切图与九宫格：不懂九宫格与多分辨率适配的 UI 美术会被程序追着跑；
  • 动效：界面呼吸、弹出、转场动效已经是标配要求（AE/引擎内实现）。

■ 大学四年怎么走
4-YEAR PLAN
按 2024 级培养方案的课程节奏编排 · 以教务最新通知为准
1
大二 · 构成与图标 FOUNDATION
构成设计 + 图标简化训练
UI 的设计基本功从"减法"开始：把复杂的东西画小、画清楚：
  • 课内：构成设计认真上——点线面、疏密、视觉层级就是 UI 的全部语言；
  • 图标训练：找 20 个复杂实物，逐个简化成 24×24 的图标，练形体归纳；
  • 规范预热：了解九宫格、切图、多分辨率适配是什么（B 站搜"游戏 UI 切图规范"）；
  • 输入：收藏 10 套你喜欢风格的完整游戏界面，分析它们的层级和统一性。
2
大二暑假 · 规范与第一套界面 SPEC & FIRST SET
拆一套开源 UI + 自己出第一套
从"会画图标"到"会出可实现的界面"：
  • 拆解：找一套开源游戏 UI 资源拆开看——怎么切图、怎么命名、怎么适配不同分辨率；
  • 第一套：PS / Figma 出一套完整界面（主界面 + 背包页），严格执行切图规范；
  • 工具：Figma 组件化管理用起来（团队协作加分项）；
  • 课内衔接：游戏视觉设计（大三上）开课之前，这套作业就是你最好的预习。
3
大三 · 成套界面 + 动效 FULL SET & MOTION
1~2 套完整界面 + AE 动效演示
作品集主力年：一套风格统一、覆盖多页面的界面 > 一百个零散图标：
  • 成套：主界面 + 战斗 HUD + 背包 / 商店二级页，同一世界观同一风格，2 套起步；
  • 动效：After Effects 做弹窗、转场、按钮呼吸的动效演示——UI 动效已是标配要求；
  • 实现意识：了解 UGUI 怎么搭界面（数媒技做得到），知道自己的设计图如何被程序实现；
  • 课内：游戏视觉设计、网页前端技术（理解"设计稿如何被实现"）认真上。
4
大四 · 成集 + 投递 PORTFOLIO
2~3 套成集 + 规范背书
UI 应聘看的是"成套的、可实现的、有规范的"作品：
  • 2~3 套不同风格的完整界面成集，每套附设计说明 + 切图规范 + 动效视频；
  • 加分项：把其中一套真的用 UGUI 搭出来录屏——懂实现的 UI 美术非常稀缺；
  • 面试高频题：信息层级怎么定、图标风格怎么统一、九宫格怎么切——都用你的套图回答；
  • 投递：游戏 UI 相对看重手绘功底，大一的素描功底在这里会回来帮你，见薪资招聘页。

■ 作品集长什么样 · 常见误区
PORTFOLIO & TRAPS
作品集定生死 · 别在错误方向上努力
  • 成套 > 零散：一套风格统一的完整界面 > 一百个零散图标；
  • 附规范：切图规范、九宫格示意、适配说明，证明你懂实现；
  • 常见误区：只画图标不懂九宫格；只管好看不管实现成本；
  • 加分项：会用引擎把界面真的搭出来（UGUI）——数媒技做得到。
