💡 一句话定位 给游戏"做壳"的岗位：界面、图标、HUD、动效。本质是平面设计的游戏化——设计感是上限，切图规范与实现意识是下限，数媒技的构成设计课直接对口。
■ 这个细分到底在拼什么
WHAT IT TAKES
先看清门槛 · 再决定要不要投入
  • 信息层级：界面首先解决"玩家先看哪"，其次才是好看；
  • 图标语言统一：一套图标要有统一的形体语言、描边粗细、透视规则；
  • 切图与九宫格：不懂九宫格与多分辨率适配的 UI 美术会被程序追着跑；
  • 动效：界面呼吸、弹出、转场动效已经是标配要求（AE/引擎内实现）。

■ 大学四年怎么走
4-YEAR PLAN
按 2024 级培养方案的课程节奏编排 · 以教务最新通知为准
1
大二 · 打构成底子 FOUNDATION
构成设计 + 第一批图标练习
配合课内《构成设计》练形体归纳：把复杂物简化成 24×24 的图标，是最快的设计训练。
2
大二暑假 · 补规范 SPEC
九宫格 / 切图规范 / 多分辨率适配常识
找一套开源游戏 UI 拆开看：怎么切、怎么命名、怎么适配，理解"可实现的 UI"长什么样。
3
大三 · 成套界面 FULL SET
一套完整游戏界面 + 动效演示
主界面 + 战斗 HUD + 背包/商店等二级页，统一风格，配 AE 动效演示视频。
4
大四 · 成集 PORTFOLIO
UI 作品集终稿
2~3 套不同风格的完整界面成集，每套附设计说明与切图规范。
■ 作品集长什么样 · 常见误区
PORTFOLIO & TRAPS
作品集定生死 · 别在错误方向上努力
  • 成套 > 零散：一套风格统一的完整界面 > 一百个零散图标；
  • 附规范：切图规范、九宫格示意、适配说明，证明你懂实现；
  • 常见误区：只画图标不懂九宫格；只管好看不管实现成本；
  • 加分项：会用引擎把界面真的搭出来（UGUI）——数媒技做得到。
