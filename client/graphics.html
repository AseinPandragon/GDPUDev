■ 这个细分到底在拼什么
WHAT IT TAKES
先看清门槛 · 再决定要不要投入
  • 图形学数学：线性代数、三角函数、投影变换，绕不开；
  • 渲染管线全流程：一帧从 CPU 提交到屏幕上每一步发生什么；
  • Shader 编写：和渲染 TA 重合，但要求更接近底层实现；
  • C++ 基本功：UE 路线和引擎向都离不开。
■ 工具链 与 课内对应课程
TOOLS & COURSES
工具是手段不是目的 · 招聘看的是"用工具做出的东西"
工具 / 课程作用 / 对应环节
GAMES101（B站 / 课程主页）理论主课，作业必须做；
LearnOpenGL（learnopengl.com，有中文）动手侧主线：从画三角形到完整场景；
3Blue1Brown 线代本质（官网免费）先建几何直觉，再回课本刷题；
RenderDoc（renderdoc.org）抓帧定位渲染问题、验证自己写的 pass；
课内：线性代数 / 计算机图形学课内能提供的直接弹药，成绩就是入场券。
■ 这个岗位的一天 · 实际工作内容
A DAY IN LIFE
入职前先知道每天到底在干什么
  • 上午：看渲染 bug——阴影异常、半透明排序、效果在真机上不对；
  • 主力时间：实现渲染特性——和 TA 配合把表现需求落成稳定实现；
  • 画质与性能平衡——每个特性都有代价，调参定档位；
  • 产出物：渲染特性代码 + 平台表现验证报告。

■ 大学四年怎么走
4-YEAR PLAN
按 2024 级培养方案的课程节奏编排 · 以教务最新通知为准
1
大一 · 线代优先（这门课就是入场券）
线性代数学到"能出题考别人"的程度，期末目标 90+
做什么：向量、点积叉积的几何意义、矩阵乘法、齐次坐标与投影——每个概念都用几何直觉重新理解一遍，不是背公式。推荐用 3Blue1Brown《线性代数的本质》（免费视频，B站有搬运）建立直觉，再回课本刷题固化。
验收标准：能给别人讲清"为什么旋转是乘矩阵、平移为什么需要齐次坐标"。
避坑：线代不牢直接学图形学 = 每页都在还债；这门课多花的每一小时都在给大二大三省时间。
2
大二 · GAMES101（理论主课）
跟完 GAMES101 全部课程与作业，写出光栅器和着色器
做什么：闫令琪 GAMES101（B站全集 / 课程主页），重点是做作业——光栅化、变换、着色、光线追踪的作业全做，不做作业的掌握程度差距巨大。配套阅读 LearnOpenGL（learnopengl.com，有中文翻译）动手侧。
验收标准：作业全部提交并通过，且能画出"一帧从 CPU 提交到屏幕"的完整流程图。
避坑：只看视频不做作业 = 知识点全懂、代码全不会写。
3
大三 · SRP 实践（把理论接进引擎）
做 URP 定制渲染小项目：自定义 RenderPass + 后处理 + 至少一个手写 Shader 特性
做什么：在 Unity URP 里做一个小项目：自定义 RenderFeature/RenderPass（描边、马赛克、径向模糊任选）、一个完整的后处理链，并读 URP 源码里"一帧是怎么被组装起来的"。抓帧用 RenderDoc 验证自己画的每一帧。
验收标准：一个可切换开/关的自定义 pass + 一篇"这个 pass 每一步在做什么"的笔记。
避坑：只会调材质面板参数不是图形编程——从你写第一个 C# RenderPass 开始才算入场。
4
大四 · 专项面试（数学 + 管线 + 算法三线并进）
图形面试专项：每类题建立自己的答案模板，全部落到白板能写
做什么：分三类刷题——数学（MVP 变换、透视插值矫正、法线变换）、管线（一帧的完整流程、深度与透明排序）、算法（软光栅三角形填充、双边滤波），每类整理自己的答案模板并落成文档。作品集同步收口：SRP 项目 + 笔记归档。
验收标准：模拟面试三类题各抽一道，白板能写、口头能讲。
避坑：没读过的源码/没做过的特性别写进简历——图形面试的追问没有底线。
■ 作品集长什么样 · 常见误区
PORTFOLIO & TRAPS
作品集定生死 · 别在错误方向上努力
  • 标配：渲染特性 demo + 每个特性的原理文档；
  • 误区：只会引擎里调参数没手写过 Shader——这是美术操作不是图形编程；
  • 加分：软件光栅器、软光追这类"从零实现"，说服力极强。
