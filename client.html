■ 深挖方向 02：客户端程序（Unity C# / UE C++）
4 STEPS
数媒技走的人最多的路 · 从"会拖组件"到"能独立交付完整游戏"
STEP_01 · 语言基础（一切的地基） C# FIRST
先把 C# 学扎实：唐老狮 C# 四部曲
直接跳过语言去拖引擎组件，是数媒技学生最常见的翻坑方式。推荐的免费系统课是唐老狮（B站：一唐老狮一）的 C# 四部曲：入门 → 核心 → 进阶 → 数据结构与算法，讲得细、有作业、节奏适合自学，B站整套免费看。四部曲全部过完，你才有资格谈"会用 Unity 写逻辑"。
唐老狮 · B站个人空间 C#入门 → C#核心 → C#进阶 → 数据结构与算法 免费 · 有课后作业
STEP_02 · 引擎实操（与 STEP_01 后半并行） MAKE IT PLAYABLE
Unity 入门：跟着做，别只看
唐老狮的 Unity 系列覆盖 MonoBehaviour 生命周期、UI（UGUI）、物理、动画、寻航等全部常用模块，跟着把每个模块的小案例做出来；同时配合 Unity 官方文档查 API——教程负责入门，文档负责精确。目标：能不抄教程独立做出贪吃蛇 / 打飞机 / 平台跳跃级别的小游戏。
唐老狮 · Unity 系列教程 Unity Learn 官方教程 Unity 官方文档
STEP_03 · 内功（大二下~大三上） DATA STRUCTURE + FRAMEWORK
数据结构、设计模式与"框架感"
校招笔试躲不开数据结构与算法（LeetCode 简单~中等量级即可），而面试更看你在项目里怎么组织代码：对象池、状态机、事件系统、单例、MVC 分层——这些"框架感"是从写 Demo 到写项目的分水岭。建议每个小机制都自己封装一遍，再回头看别人的实现对比。
LeetCode 力扣 对象池 / 状态机 / 事件系统 / UI框架
STEP_04 · 作品集（大三上必须启动） SHIP IT
客户端的作品集长什么样
  • 1~2 个完整可玩的游戏：能安装、有音效、有结算、能重开，最好打过真机包（安卓 APK 能给别人装上玩）。
  • GitHub 仓库：README 写清楚玩法、架构图和技术亮点（对象池怎么省内存、UI 框架怎么分层）。
  • UE C++ 支线（加分项）：想走 UE 方向的，C++ 基础（唐老狮也有 UE 系列的 C++ 四部曲）→ UE 官方文档 → C++ 写小游戏逻辑，应届 UE 岗少但竞争更小。
唐老狮 · UE C++ 四部曲 UE 官方文档 GitHub
💡 一句话总结客户端方向 客户端 = 语言底子（C# 四部曲 / C++）× 引擎系统知识（UI/物理/动画/热更）× 完整项目（打包到真机、别人真的玩过）。面试官问"你这个项目的内存峰值多少、包体多大"，答不上来就是 Demo 选手。
■ 亲历踩坑实录 · 客户端篇（为什么"课本外"的东西更重要）
2 WAR STORIES
以下全部来自我们真实项目 · 教程里不会写 · 只有进项目才碰得到
WAR STORY_01 · 热更 HOTUPDATE SPLIT
改一行业务代码，玩家要重下 6.55MB？热更分包的教训
热更 DLL 最初混打在一个包里，改一行业务代码玩家就要全量重下。后来把 DLL 按"业务 / AOT / 第三方"拆成三个子目录，改一行业务代码的重下体积从 6.55MB 降到约 0.6MB。资源分包规则（共享资产重复打包）也是同类问题——教程只教"怎么打热更包"，不教"怎么打得让玩家少下载"。
YooAsset / HybridCLR 实战 分包是体验问题，不只是技术问题
WAR STORY_02 · 运行时 DOMAIN RELOAD TRAP
Play 模式中途改脚本，教程协程直接"暴毙"
Unity 在 Play 模式下改代码触发域重载（Domain Reload），静态状态全部重置、协程被杀——我们的新手引导协程就是这样变成"半死态"的：弹窗残留但引导流程已死。结论进项目才懂：验证流程必须"退出 Play → 等编译完 → 重进"，以及业务代码要能扛住"任意时刻被重置"。
Domain Reload 会杀协程 引擎机制坑 · 文档里有但你不信
