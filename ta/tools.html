■ 这个细分到底在拼什么
WHAT IT TAKES
先看清门槛 · 再决定要不要投入
  • Python：Maya / Blender 插件的主力语言，字符串与文件批处理要顺手；
  • DCC 软件脚本接口：Maya cmds/mel、Blender bpy，会查官方文档比背 API 重要；
  • 规范思维：资产命名、目录结构、导入规则——规范是管线的基础设施；
  • 一点 UI：PySide 让工具能交付给非技术同事用。
■ 工具链 与 课内对应课程
TOOLS & COURSES
工具是手段不是目的 · 招聘看的是"用工具做出的东西"
工具 / 课程作用 / 对应环节
Python + PySide2写 Maya/Blender 插件与工具界面的事实标准；
Maya / Blender 官方 SDK 文档API 记不住没关系，会查会试就行；
版本管理思维美术资产也要进 Git LFS 或 Perforce——规范从你开始；
课内：Python 程序设计多数学校大二开，认真上，这门课直接对口；
课内：数据库原理批量数据处理的思维底子。
■ 这个岗位的一天 · 实际工作内容
A DAY IN LIFE
入职前先知道每天到底在干什么
  • 上午：收需求——美术说"贴图要批量改名"，你要追问出真实痛点是什么；
  • 主力时间：写工具 / 改插件——从脚本到带界面的小工具，写完自己先当用户测一遍；
  • 答疑与迭代——工具发布后处理使用问题，收集下一个需求；
  • 产出物：DCC 插件、批处理脚本、资产规范文档。
■ 面试与校招 · 会考什么
INTERVIEW MAP
Python 手写与"工具思维"是两道主门槛
考察环节常见形式与真题方向
Python 手写文件批处理、字符串解析是常客，不用会算法竞赛但要会写"能用的脚本"；
场景题"美术每天花 2 小时手工检查贴图，你怎么帮"——考需求拆解与落地；
工具复盘讲一个你写过的工具：需求、方案、踩坑、最终省了多少人时；
规范设计资产命名与目录规范怎么设计才不会随项目膨胀而失控。

■ 作品集长什么样 · 常见误区
PORTFOLIO & TRAPS
作品集定生死 · 别在错误方向上努力
  • 标配：工具演示 gif/视频 + 使用说明 + 一段核心代码；
  • 量化是灵魂：把 2 小时手工流程压到 5 分钟，比十个炫技功能有说服力；
  • 规范文档也算作品：能看到你的系统性思维；
  • 误区：只炫技不解决真实痛点——没人用的工具等于没做。
