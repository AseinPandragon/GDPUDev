■ 这个细分到底在拼什么
WHAT IT TAKES
先看清门槛 · 再决定要不要投入
  • 图形学数学：矩阵与向量变换、光照模型，线代学不牢这里寸步难行；
  • Shader 语言：HLSL / ShaderLab / GLSL 至少一门写熟，抄得出来更要改得动；
  • 审美判断：能看出"哪里不对"并用图形学语言说清原因；
  • 渲染管线理解：不透明与透明排序、ZTest/ZWrite、URP 或 UE 的渲染流程。
■ 工具链 与 课内对应课程
TOOLS & COURSES
工具是手段不是目的 · 招聘看的是"用工具做出的东西"
工具 / 课程作用 / 对应环节
Unity Shader Graph / 手写 Shader入门用 Graph，进阶必须手写；UE 走 Material + 蓝图；
RenderDoc（renderdoc.org，免费）抓帧分析是日常：看 draw call、看纹理、定位渲染错误；
书单《Unity Shader 入门精要》（豆瓣 / 配套源码）入门；进阶 Real-Time Rendering（官网提供部分章节试读）；
视频课B站庄懂《技术美术入门课》（入口）+ GAMES101（B站 / 课程主页）；
进阶阅读Catlike Coding（catlikecoding.com）与毛星云学习笔记（GitHub）；
课内：线性代数大一必修，图形学的地基，这门课的成绩约等于 shader 上手速度；
课内：计算机图形学（如开设）没有就自学 GAMES101，作业认真做。
■ 这个岗位的一天 · 实际工作内容
A DAY IN LIFE
入职前先知道每天到底在干什么
  • 上午：过渲染单——花屏、排序错、半透明异常，逐条定位是美术配置还是代码问题；
  • 主力时间：写渲染特性——卡通渲染描边、假反射、后处理调参，和美术来回对效果；
  • 抓帧分析——RenderDoc 一帧一帧看，定位性能与错误；
  • 产出物：Shader / 材质资产 + 效果对比说明文档。
■ 面试与校招 · 会考什么
INTERVIEW MAP
数学和管线是这个细分的必考题 · 现场写 Shader 是常态
考察环节常见形式与真题方向
现场写 / 读 Shader如实现一个 Lambert 光照加描边，或解释一段现成代码在做什么；
数学题矩阵变换、为什么法线变换要用逆转置矩阵——考理解不是背诵；
效果拆解给一张游戏截图，说清这个效果可能的实现思路与代价；
管线题不透明与透明物体的渲染顺序、ZTest 与 ZWrite 的区别，答不出很减分。
■ 大学四年怎么走
4-YEAR PLAN
按 2024 级培养方案的课程节奏编排 · 以教务最新通知为准
1
大一 · 地基（两件事，别贪多）
线性代数拿下 85+，通读《Unity Shader 入门精要》并跑通配套源码
做什么：①线性代数当专业课学——向量点积叉积、矩阵变换是 Shader 的母语，期中期末目标 85 分以上；②《Unity Shader 入门精要》（冯乐乐著，豆瓣 8.9 分）通读一遍，配套源码仓库（github.com/candycat1992/Unity_Shaders_Book）逐章导入 Unity 跑通。
验收标准：合上书能说清"一个顶点从模型空间到屏幕经过了哪几次变换、每次变换用什么矩阵"。
避坑：别一上来就抄网上炫酷效果——先手写 20 个"变色/半透明/简单描边"级别的迷你 Shader 练打字感，抄得出来不代表写得出来。
2
大二 · 复现（视频课 + 理论课双线）
跟完庄懂 TA 入门课复现 6 个经典效果，同步刷 GAMES101 补理论，每篇写实现笔记
做什么：主跟 B站庄懂《技术美术入门课（美术向）》（课程入口与作业），把半兰伯特、高光、菲涅尔、描边逐个手写复现；理论跟不上就同步刷 GAMES101（闫令琪，B站全集，课程主页）。
验收标准：描边、卡通着色、溶解、水面扰动等 6 个效果各一篇实现笔记（效果对比图 + 思路 + 踩坑），发布到知乎或 CSDN——这就是作品集的第一批存货。
避坑：只看视频不动手等于白学，庄懂课的作业必须交；笔记里至少一段"我一开始错在哪"，这种内容面试官最爱看。
3
大三 · 统一风格（TA 思维的分水岭）
做"同套 Shader 管全场景"的风格化渲染 demo，学会用 RenderDoc 抓帧
做什么：把大二的效果整合进一个完整小场景（一个角色 + 一套环境），所有材质共用你写的 Shader 体系——这是 TA 思维和"特效爱好者"的分水岭。同步学会 RenderDoc 抓帧：看一次 draw call、看一张贴图实际采样了什么。进阶资源：Catlike Coding 教程（英文但质量顶级）与毛星云《游戏程序员学习笔记》（GitHub 仓库）。
验收标准：demo 有一套统一风格 + 一篇 RenderDoc 分析笔记（哪怕只分析 5 个 draw call）。
避坑：别贪大世界——一个房间级场景打磨到位，比烂尾的开放世界值钱十倍。
4
大四 · 定稿（作品集 + 面试双线收口）
作品集收敛为三件套，图形学面试高频题（变换/管线/光照模型）讲两遍
做什么：作品集收敛为"6 篇实现笔记 + 1 个风格化场景 demo + 1 份 RenderDoc 分析"，每篇按"效果对比图 → 思路 → 踩坑"结构排版。面试高频题用 GAMES101 课件自测：MVP 变换、法线为什么用逆转置矩阵、透明物体排序、Blinn-Phong 与 PBR 的区别——每题练到能用嘴讲 3 分钟。
验收标准：找同学当面试官模拟一轮，全程不卡壳。
避坑：简历别写没用过的名词（比如没做过 PBR 就别写"熟悉 PBR 管线"），TA 面试官一定会追问到底。
■ 作品集长什么样 · 常见误区
PORTFOLIO & TRAPS
作品集定生死 · 别在错误方向上努力
  • 标配：效果对比图（Before/After）+ 每个效果的实现思路说明；
  • 加分：RenderDoc 抓帧分析截图，证明你有调试能力而不只是会拖参数；
  • 一个统一风格的场景胜过十个孤立特效——工程化意识是 TA 和"特效爱好者"的分界线；
  • 误区：只会抄网上 Shader 不懂原理，面试一问"为什么这么写"就穿帮。
