STEP_01 · 地基（大二前打完最划算） GAMES 101 → 202 → 104
图形学三件套：GAMES 101 / 202 / 104
国内图形学入门公认的起点，B站就能看，不用管它是哪年录的——图形学基础的衰减期比框架长得多。
  • GAMES 101 现代计算机图形学入门：变换、光栅化、着色、光线追踪。作业认真写，光看不行。它决定你能不能看懂 Shader 背后的数学。
  • GAMES 202 高质量实时渲染：阴影、全局光、实时降噪——直接对应游戏渲染岗的日常话题。
  • GAMES 104 现代游戏引擎：建立"引擎全局观"，知道一个引擎由哪些系统拼起来。作业量力而行，但一定要看完，它会改变你看 Unity/UE 的方式。

STEP_02 · 引擎双线（与 STEP_01 并行） UNITY: WRITE / UE: BREAK
Unity 里动手写，UE 里开眼界拆
两条线不是二选一，是分工不同：
  • Unity 线（动手）：ShaderLab / HLSL 从最简单的 Unlit 开始写起，逐个实现卡通着色、描边、溶解、billboard、屏幕后处理。每个效果录一段视频存进作品集文件夹。
  • UE 线（拆解）：去看官方工程示例（如 Lyra、City Sample），拆解官方插件——重点不是学 UE API，而是看"一个工业级项目怎么组织材质库、后处理栈、资产管线"。见过好结构，才知道自己写的有多野。

WAR STORY_01 · 渲染排序 URP CAMERA STACK
UI 弹窗怎么调 Layer 都不生效？因为 URP 里 Layer 根本不管排序
技能弹窗死活显示不出来/层级错误，查了半天 Layer 剔除——真相是：URP 的 Overlay 相机栈里，Layer 只管相机剔除，实际显示顺序由相机列表顺序和 Sorting Layer 决定。最后靠把弹窗挂到最上层 Canvas + 指定 Sorting Layer 才解决。
GAMES101 教原理 "引擎具体怎么排"只能靠项目毒打
WAR STORY_02 · 深度与遮挡 Z-TEST TRAP
世界空间图标被场景模型"吃"掉一半：ZTest 的教训
给技能做箭头指示图标，按物体包围盒定位后仍然被挡——精灵枢轴和半深度都没算进去。世界空间 UI/图标必须在锚点定位之外额外考虑与相机的深度关系（沿相机方向再推一段），否则 ZTest 会替你做"正确的"遮挡，挡掉你想显示的东西。
ZTest 是"对的"，但不是你要的
WAR STORY_03 · 资源与打包 SHADER STRIPPING
编辑器里好好的，真机上材质全变粉色（或直接报空）
运行时用 Shader.Find 动态建材质，编辑器一切正常，真机上直接 ArgumentNullException 中断加载——因为没被资源引用的 shader 打包时会被裁剪，真机上 Find 返回 null。正确做法是多候选查找 + 内置材质兜底 + 全失败就跳过赋值。
打包管线知识 不进项目永远碰不到
WAR STORY_04 · 粒子特效 VFX LOOP TRAP
循环特效越叠越亮：burst 粒子的 duration 陷阱
把循环特效 main.loop 打开后，画面上的粒子一轮比一轮多——原因是 ParticleSystem 的 duration 没有覆盖到最长粒子寿命，burst 每个周期都在叠。调 VFX 不是拖拖参数，每一条曲线和时长都要能解释。
loop=true 时 duration ≥ 最长寿命
